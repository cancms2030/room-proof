作为酒店保洁主管，你是否遇到过这样的问题：不同的保洁员对"干净"的理解各不相同，客房检查时全凭主管个人标准判断，导致质量参差不齐？

**标准化是提升酒店客房保洁质量的核心。** 今天，我们整理了一份完整的酒店客房检查SOP清单，覆盖9大核心区域，建议收藏备用。

## 一、床铺区域检查标准

| 检查项   | 合格标准                             |
| :------- | :----------------------------------- |
| 床单被套 | 无污渍、无褶皱、无毛发，四角包边平整 |
| 枕头     | 枕套无污渍，枕头拍打蓬松，摆放对称   |
| 床尾巾   | 平整无褶皱，居中摆放                 |
| 床底     | 无垃圾、无灰尘                       |

## 二、卫生间检查标准

| 检查项     | 合格标准                           |
| :--------- | :--------------------------------- |
| 马桶       | 内外壁无污渍，消毒封条完整         |
| 洗手台     | 无水渍、无皂渍，镜子无手印         |
| 淋浴区     | 地面无积水，墙面无水垢，地漏无毛发 |
| 毛巾/浴巾  | 干净柔软，无破损，摆放整齐         |
| 一次性用品 | 牙具、梳子等补齐，包装无破损       |

## 三、地面与墙面检查标准

- **地面**：无脚印、无污渍、无碎屑，地毯无沙粒感
- **墙面**：无手印、无污渍、无蜘蛛网
- **踢脚线**：无积灰、无破损

## 四、家具与设施检查标准

- **衣柜**：衣架齐全，柜内无灰尘，门开合顺畅
- **电视/空调**：遥控器摆放到位，设备功能正常
- **床头柜**：表面无水印，电话/便签齐全
- **窗帘**：开合顺畅，无脱钩，遮光完好

## 五、细节检查（最容易遗漏）

- 门铃/门牌：清洁无灰尘
- 开关面板：无指纹印
- 垃圾桶：内无异味，套袋规整
- 房间气味：无异味，无烟味
